## Install yabridge
[On fedora](https://copr.fedorainfracloud.org/coprs/patrickl/wine-tkg/)

## Install Vsts

To add a vst2 (.dll),vst3 or clap into yabridge, drop this files into your default vst folder. like `~/.vsts/`    

Then run `yabridgectl sync`, this should be enougth to register this vsts to yabridge.

## install .exe vsts
Install the .exe with wine as usual.     
the installed vst should be located at `~/.wine/drive_c/Program\ Files`, then select the folder where you plugins are located, or the sigle plugin, create a symbolic link to your default vst folder.   
`ln ~/.wine/drive_c/Program\ Files/<VST FOLDER> ~/.vsts/<VST FOLDER>` doing this you can sync yabridge and it will find your new vst.   
Run `yabridgectl sync` to sync
